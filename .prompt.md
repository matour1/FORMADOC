## Créer une route upload (avec validation stricte)

**Checklist :**
- [ ] MIME type réel validé (pas juste extension)
- [ ] Taille max 50 MB
- [ ] Stockage en `storage/uploads/` (hors web root)
- [ ] Validation via Form Request
- [ ] Erreurs gracieuses

```php
// routes/web.php
Route::post('/documents/upload', [DocumentController::class, 'upload'])
    ->name('documents.upload');

// app/Http/Controllers/DocumentController.php
public function upload(StoreDocumentRequest $request)
{
    try {
        $file = $request->file('document');
        
        // MIME réel (Symfony détecte automatiquement)
        $mimeType = $file->getMimeType();
        Log::info('File uploaded', ['mime' => $mimeType, 'size' => $file->getSize()]);
        
        // Stocker
        $path = $file->store('documents', 'storage');
        
        // Lancer détection
        $document = Document::create([
            'filename' => $file->getClientOriginalName(),
            'path' => $path,
            'status' => 'pending'
        ]);
        
        DetectDocumentStructure::dispatch($document);
        
        return redirect()->route('documents.show', $document)
            ->with('success', 'Document upload avec succès, analyse en cours...');
    } catch (Exception $e) {
        return back()->withError('Erreur upload : ' . $e->getMessage());
    }
}
```

## Traiter un document (pipeline complet)

**Ordre d'exécution :**
1. Charger du fichier depuis `storage/`
2. Convertir en texte brut (DOCX → txt, PDF → txt)
3. Valider non-vide
4. TitleDetectionService (LLM)
5. LegendDetectionService (Regex)
6. Sauvegarder JSON dans `document_structures`

```php
class DetectDocumentStructure implements ShouldQueue
{
    public function handle()
    {
        $text = $this->extractText($document->path);
        
        // Détection titres
        $titles = app(TitleDetectionService::class)->execute($text);
        
        // Détection légendes
        $legends = app(LegendDetectionService::class)->execute($text);
        
        // Sauvegarder
        DocumentStructure::updateOrCreate(
            ['document_id' => $document->id],
            ['structure' => json_encode(['titles' => $titles, 'legends' => $legends])]
        );
        
        $document->update(['status' => 'detected']);
    }
}
```

## Appeler DeepSeek API

**Important :** gestion erreurs, retry, timeout

```php
use Illuminate\Support\Facades\Http;

class TitleDetectionService
{
    public function execute(string $text): array
    {
        $prompt = 'Tu es un outil d\'analyse...' ; // Voir PROMPTS_ET_TESTS.md
        
        $response = Http::retry(3, 100) // Retry 3 fois, délai 100ms
            ->timeout(30)
            ->withHeaders(['Authorization' => 'Bearer ' . config('deepseek.api_key')])
            ->post('https://api.deepseek.com/v1/chat/completions', [
                'model' => 'deepseek-v4-flash',
                'messages' => [
                    ['role' => 'system', 'content' => $prompt],
                    ['role' => 'user', 'content' => $text]
                ]
            ]);
        
        if ($response->failed()) {
            throw new Exception('DeepSeek API error: ' . $response->body());
        }
        
        return $this->parseResponse($response->json());
    }
}
```

## Créer une vue Blade avec formulaire

**Bonnes pratiques :**
- Utiliser `@csrf` pour toute form POST
- Afficher erreurs `@error` 
- Bootstrap classes
- Accessible (labels liés)

```blade
@extends('layouts.app')

@section('content')
<div class="container mt-5">
    <div class="row justify-content-center">
        <div class="col-md-6">
            <h2>Nouvelle mise en forme</h2>
            
            @if ($errors->any())
                <div class="alert alert-danger">
                    <ul>
                        @foreach ($errors->all() as $error)
                            <li>{{ $error }}</li>
                        @endforeach
                    </ul>
                </div>
            @endif
            
            <form method="POST" action="{{ route('documents.upload') }}" enctype="multipart/form-data">
                @csrf
                
                <div class="mb-3">
                    <label for="document" class="form-label">Votre rapport</label>
                    <input type="file" class="form-control @error('document') is-invalid @enderror" 
                           id="document" name="document" accept=".docx,.pdf,.txt" required>
                    @error('document')
                        <span class="invalid-feedback">{{ $message }}</span>
                    @enderror
                </div>
                
                <button type="submit" class="btn btn-primary">Télécharger</button>
            </form>
        </div>
    </div>
</div>
@endsection
```
